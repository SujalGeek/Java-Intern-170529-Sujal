different types of ec2 instance type:
1.general purpose
they have good diversity of workloads such as web servers or code repositories

and they have great balance between compute, memory and networking
t2.micro comes under this category

2. compute optimized 

they are great for the compute intensive tasks that require high performance processors;
batch processing workloads
media transcoding
high performance web servers
gaming servers and high performance computing(hpc)
scientific modelling and ml 

all the c series comes under this categories


3.memory optimized 
they are used for the fast performance for workloads that process large data sets in memory
the use cases:
high performance , distributed web scale and then in memory databases optimized for BI and applications performing real time processing of big unstructured data

4. storage optimized
great for the storage intensive tasks that require high, sequential read and write access to large data sets on local storage


use cases:
high frequency online transaction processing(OLTP) systems
relational & NoSQL databases
cache for in memory databases
data warehousing applications
distributed file systems
